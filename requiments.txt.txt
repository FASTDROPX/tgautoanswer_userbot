## Минимальный файл для быстрой установки:

```txt
telethon==1.28.5
```

## Как установить зависимости:

### Базовый вариант (только для запуска):
```bash
pip install -r requirements.txt
```

### Полный вариант (с инструментами разработки):
```bash
# Установите зависимости
pip install telethon==1.28.5

# Для создания exe-файла (опционально)
pip install pyinstaller==5.13.0

# Для тестирования (опционально)
pip install pytest==7.4.0 pytest-asyncio==0.21.0
```

### Для разных операционных систем:

**Windows:**
```powershell
# Установите Python 3.8+ с официального сайта python.org
# Убедитесь, что выбрали опцию "Add Python to PATH"
python -m pip install --upgrade pip
pip install telethon==1.28.5
```

**Ubuntu/Debian:**
```bash
# Установите Python и Tkinter
sudo apt-get update
sudo apt-get install python3 python3-pip python3-tk

# Установите зависимости
pip3 install --upgrade pip
pip3 install telethon==1.28.5
```

**macOS:**
```bash
# Установите через Homebrew
brew install python-tk
pip3 install telethon==1.28.5
```

## Проверка установки:

```bash
# Проверьте версию Python
python --version

# Проверьте установку Telethon
python -c "import telethon; print(f'Telethon версия: {telethon.__version__}')"

# Запустите программу
python FASTBOT.py
```

## Если возникают проблемы:

1. **Ошибка с tkinter:**
   - Windows: Переустановите Python с официального сайта, выбрав опцию "tcl/tk"
   - Ubuntu: `sudo apt-get install python3-tk`
   - macOS: `brew install python-tk`

2. **Ошибка с telethon:**
   ```bash
   # Обновите pip
   pip install --upgrade pip
   
   # Попробуйте установить без кэша
   pip install --no-cache-dir telethon==1.28.5
   ```

3. **Проблемы с версией Python:**
   Убедитесь, что у вас Python 3.8 или выше:
   ```bash
   python --version
   ```

## Docker (опционально):
