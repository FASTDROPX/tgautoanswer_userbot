# Telegram Bot Manager

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Telethon](https://img.shields.io/badge/Telethon-1.34+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

**Многофункциональный менеджер Telegram ботов с графическим интерфейсом на Python**

## 🚀 Возможности

### 🤖 Автоответчик
- **Первое сообщение**: "Я - автоответчик! Если есть вопросы, пишите сразу."
- **Повторные сообщения**: "Скоро отвечу!" (1 раз в 20 минут)
- **Умный таймер**: Автоматический контроль частоты ответов

### 📤 Статусы отправки файлов
- Автоматическое определение типа файла (фото, видео, аудио, документы)
- Красивые статусы отправки
- Автоматическое удаление статусов через 3 секунды

### 👥 Управление пользователями
- Отслеживание всех пользователей, которые писали в ЛС
- Закрепленное сообщение со списком пользователей
- Автоматическое обновление списка

### 🔐 Управление аккаунтами
- **Добавление по номеру телефона** (стандартная авторизация)
- **Добавление по юзернейму** (API ID + API Hash)
- **Ограничение в 10 аккаунтов**
- Быстрое переключение между аккаунтами
- Сохранение сессий между запусками

### 📊 Статистика
- Подробная статистика по всем аккаунтам
- Отображение статусов ботов (запущен/остановлен)
- Логирование всех событий

## 📦 Установка

### Требования
- Python 3.8 или выше
- Telegram API ключи (можно получить на [my.telegram.org](https://my.telegram.org))

### Установка зависимостей

```bash
# Установите Telethon
pip install telethon

# Или установите из requirements.txt
pip install -r requirements.txt
```

### requirements.txt:
```
telethon>=1.34.0
```

## 🖥️ Использование

1. **Запустите программу:**
```bash
python FASTBOT.py
```

2. **Получите API ключи:**
   - Зайдите на [my.telegram.org](https://my.telegram.org)
   - Создайте новое приложение в **API Development Tools**
   - Скопируйте **api_id** и **api_hash**

3. **Добавьте аккаунт:**
   - Введите API ID, API Hash и номер телефона
   - Нажмите "Авторизовать"
   - Введите код из Telegram
   - При необходимости введите пароль 2FA

4. **Запустите бота:**
   - Нажмите "Запустить бота"
   - Бот начнет работу в фоновом режиме

## 📸 Интерфейс

Программа имеет удобный графический интерфейс с разделением на:

### Верхняя панель
- **➕ Добавить по юзернейму** - добавление аккаунта по username
- **🔀 Переключить аккаунт** - выбор активного аккаунта из списка
- **📊 Статистика аккаунтов** - информация о всех аккаунтах

### Левая панель (авторизация)
- Поля для ввода API ID, API Hash, номера телефона
- Кнопки управления: Авторизовать, Запустить бота, Остановить всех, Очистить, Удалить аккаунт
- Статус текущего аккаунта
- Выпадающий список сохраненных аккаунтов

### Правая панель (логи и информация)
- **Логи** - все события в реальном времени
- **Список аккаунтов** - статус каждого аккаунта
- **Управление логами** - очистка и сохранение

## 🔧 Функции

### Автоответчик
Бот автоматически отвечает на личные сообщения:
- Первое сообщение от пользователя: "Я - автоответчик! Если есть вопросы, пишите сразу."
- Повторные сообщения: "Скоро отвечу!" (не чаще чем раз в 20 минут)

### Статусы отправки файлов
При отправке любого медиафайла бот показывает соответствующий статус:
- 🖼️ Фото: "Отправляю фото, подожди⏩"
- 🎥 Видео: "Отправляю видео, подожди⏩"
- 🎵 Аудио: "Отправляю аудио, подожди⏩"
- 📄 Документы: "Отправляю документ, подожди⏩"

Статусы автоматически удаляются через 3 секунды.

### Управление аккаунтами
- **До 10 аккаунтов** в одном приложении
- **Автозагрузка** последнего использованного аккаунта
- **Быстрое переключение** между аккаунтами
- **Сохранение данных** между запусками программы

### Отслеживание пользователей
- Сохраняет всех пользователей, которые писали в ЛС
- Обновляет закрепленное сообщение со списком
- Данные хранятся в JSON файлах

## 📁 Структура файлов

```
telegram-bot-manager/
├── FASTBOT.py              # Основной файл программы
├── accounts.json          # Данные авторизованных аккаунтов
├── telegram_sessions.json # Данные сессий для автозаполнения
├── users_data_*.json      # Данные пользователей по аккаунтам
└── auto_responses_*.json  # История автоответов по аккаунтам
```

2. **Соблюдайте правила Telegram** - не используйте для спама
3. **Ограничение аккаунтов** - максимум 10 аккаунтов на один API
4. **Резервное копирование** - сохраняйте файлы сессий

## 🐛 Поиск и устранение неисправностей

### Ошибка авторизации
1. Проверьте правильность API ID и API Hash
2. Убедитесь, что номер телефона введен в международном формате (+7...)
3. Проверьте код из Telegram (не перепутайте с паролем 2FA)

### Бот не отвечает
1. Проверьте, запущен ли бот (статус "Бот запущен")
2. Проверьте интернет-соединение
3. Убедитесь, что аккаунт авторизован

### Проблемы с запуском
1. Убедитесь, что установлен Python 3.8+
2. Проверьте установку Telethon: `pip show telethon`
3. Запускайте через Debug режим в VS Code (F5)
