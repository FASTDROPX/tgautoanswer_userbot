# Telegram Bot Manager v2.0 🚀

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Telethon](https://img.shields.io/badge/Telethon-1.28+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

**Мощный менеджер Telegram-ботов с автоответчиком, эффектом печати и управлением до 10 аккаунтами**

## ✨ Основные возможности

### 🤖 **Умный автоответчик**
- Настраиваемые ответы для новых и существующих пользователей
- Интервалы между ответами (настраиваемые)
- Игнорирование после ваших сообщений (настраиваемое время)
- Поддержка 2FA (двухфакторной аутентификации)

### ✨ **Эффект печати сообщений**
- Анимация печати для **ВАШИХ сообщений**
- Настраиваемая скорость (10-1000 мс)
- Выбор символа курсора (█, |, _, и т.д.)
- **Умная фильтрация**: не применяется к ботам

### 📊 **Управление аккаунтами**
- **До 10 аккаунтов** одновременно
- Автоматический запуск ботов со второго запуска программы
- Индивидуальные настройки API для каждого аккаунта
- Сортировка аккаунтов по номерам

### 🛡️ **Фильтрация ботов**
- Автоматическое игнорирование сообщений от ботов
- Двойная проверка: по флагу `bot` и имени пользователя (заканчивается на 'bot')
- Не отвечает и не применяет эффект печати к ботам

### 📁 **Отправка файлов**
- Статусы отправки файлов (фото, видео, аудио, документы)
- **Мгновенное удаление статусов** после доставки файла
- Информативные сообщения о процессе отправки

## 🚀 Быстрый старт

### Требования
```bash
pip install telethon==1.28.5
```

### Установка
1. Клонируйте репозиторий
2. Установите зависимости
3. Запустите `FASTBOT.py`

### Первый запуск
1. **Добавьте аккаунт** через интерфейс
2. **Авторизуйтесь** (получите код из Telegram)
3. **Настройте автоответчик** (по желанию)
4. **Запустите бота**

**При втором и последующих запусках боты запустятся автоматически!**

## 🎛️ Интерфейс

### 📱 Панель управления аккаунтами
```
➕ Добавить аккаунт     🔄 Сменить API
⚙️ Настройки автоответчика     🗑️ Удалить все сохранения
```

### 🔐 Авторизация
- API ID (цифры)
- API Hash (строка)  
- Номер телефона (с +)
- Пароль 2FA (при необходимости)

### ⚙️ Настройки автоответчика
- **Основные настройки:**
  - Включение/выключение автоответчика
  - Отправка новым/существующим пользователям
  - Интервал между ответами (минуты)

- **Эффект печати:**
  - Включение эффекта
  - Скорость печати (10-1000 мс)
  - Символ курсора

- **Поведение после ваших сообщений:**
  - Игнорирование если вы написали последним
  - Время игнорирования (минуты)

- **Тексты ответов:**
  - Первое сообщение
  - Последующие сообщения

## 🔧 Технические особенности

### 🏗️ Архитектура
```
TelegramBotUI (GUI)
├── AccountManager (управление аккаунтами)
├── AutoResponder (автоответчик + эффект печати)
└── UserTracker (отслеживание пользователей)
```

### 📁 Структура файлов
```
FASTBOT.py              # Основной файл
accounts.json           # Данные аккаунтов
telegram_sessions.json  # Сессии Telegram
session_*.session       # Файлы сессий
users_data_*.json       # История пользователей
auto_responses_*.json   # Ответы автоответчика
auto_responder_settings_*.json # Настройки
launch_count.txt        # Счетчик запусков
```

## 🆘 Поддержка

### ❓ Частые вопросы
**Q: Почему не применяется эффект печати?**  
A: Проверьте настройки автоответчика и убедитесь, что получатель не бот

**Q: Как добавить больше 10 аккаунтов?**  
A: Лимит 10 аккаунтов установлен для стабильности работы

**Q: Почему автоответчик не отвечает?**  
A: Проверьте настройки и убедитесь, что интервал между ответами не истек

**Q: Как очистить все данные?**  
A: Используйте кнопку "Удалить все сохранения" в интерфейсе
